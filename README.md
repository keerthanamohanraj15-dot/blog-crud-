# CRUD Blog - Full Stack Blog Application

Beginner-friendly full-stack Blog CRUD project using:

- HTML, CSS, JavaScript
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs

## 🚀 Features

- User Registration
- User Login
- JWT Authentication
- Secure Password Hashing
- Create a blog
- Read/View blogs
- Update a blog
- Delete a blog
- User Dashboard
- User Profile
- Logout
- MongoDB Database
- Responsive Design

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose

### Authentication

- JSON Web Token (JWT)
- bcryptjs

### Tools

- Git
- GitHub
- VS Code
- Render
